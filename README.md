# duo-remote

iPhone Duo から、自宅の Windows PC を操作するアプリです。PCの画面を iPhone に映し、タッチやキーボードで操作します。

- PC側では、サーバー（Python）を動かします。画面を動画にして送り、iPhoneからの操作を受け付けます
- iPhone側では、アプリを入れます

まだ作っている途中です。Windows と iPhone の実機では、まだ動作を確かめていません。

## できること

- PCの画面全体、またはウィンドウ1つだけを、iPhoneに映す
- iPhone専用の作業用の画面（仮想画面）を使う。PCの本物のモニターには手を付けずに、iPhoneで作業できる（仮想ディスプレイのドライバーを入れたときだけ）
- タッチでマウスを操作する（クリック、ドラッグ、スクロールなど）。トラックパッドのように動かす方式も選べる
- 文字を入力する（iPhoneのキーボード、またはBluetoothキーボード）
- Duo を半開きにすると、上に画面、下にキーボードとトラックパッドを出す
- 映像をピンチで拡大する
- PCの音を、iPhoneで鳴らす（オンとオフを切り替えられる）
- PCとiPhoneの間で、クリップボードの文字と、写真・ファイルをやりとりする
- PCのモニターを選んで映す
- 切れたときに、自動でつなぎ直す

## はじめかた

### 1. PCでサーバーを動かす

1. このリポジトリを取ってくる。次のどちらかで取れる
   - git を使う: `git clone https://github.com/nexon1101-pixel/duo-remote.git`
   - GitHub のこのページの「Code」→「Download ZIP」で取り、展開する
2. `server` フォルダの `panel.bat` をダブルクリックする。管理画面が開き、サーバーも動き出す
   - 初回は準備に数分かかる（`start.bat` と同じ準備）。Python や ffmpeg が入っていなければ、入れるかを聞かれるので「Y」と答える
   - Windows のファイアウォールの確認が出たら、「プライベート ネットワーク」を許可する
   - `start.bat` でも動かせる。その場合は黒い画面だけが出て、サーバーが動く
3. 管理画面の「つなぎ方」に出るトークンを控えておく（iPhoneで入力する）。`start.bat` の場合は、黒い画面にトークンが出る
4. 管理画面の「つなぎ方」に、PCのIPアドレスが出る。出ないときは、コマンドプロンプトで `ipconfig` を実行し、Wi-Fi（または有線）の「IPv4 アドレス」を見る（`192.168.x.x` のような形）

`panel.bat` で動かしているときは、管理画面のウィンドウを閉じてもサーバーは動き続けます。止めるときは、管理画面の下の「管理画面を終了」を押します。`start.bat` で動かしているときは、画面を開いたままにしておきます。閉じるとサーバーも止まります。止めるときは Ctrl+C を押します。

iPhone を使う前に、PCだけでサーバーを確かめられます。サーバーを起動したまま、`server` フォルダの `check.bat` を実行すると、映像が作れているか、ウィンドウの一覧が取れるかを調べて、`[OK]` か `[NG]` で表示します（`check.bat --window` で、ウィンドウ1つだけの表示も（`--save-frame 画像.png` を付けると、そのときの映像を画像に保存する）、`check.bat --audio` で、PCの音が届くかも、`check.bat --virtual` で、仮想ディスプレイを出して映せるかも試します。音は、PCで何か鳴らしながら実行してください。仮想ディスプレイは、サーバーを `start-admin.bat` で起動しておく必要があります）。PCを操作する Claude に確認を頼むときの手順は、[docs/pc-check.md](docs/pc-check.md) にあります。

### 2. iPhoneにアプリを入れる

1. iPhone の Safari で [最新のビルド](https://github.com/nexon1101-pixel/duo-remote/releases/tag/latest) を開き、`DuoRemote.ipa` を取る
2. SideStore（または Sideloadly）で入れる

無料の Apple ID では、同時に入れられるアプリは3つまでです。

### 3. つなぐ

1. PCとiPhoneを、同じWi-Fiにつなぐ
2. アプリを開き、次を入力して「接続」を押す
   - ホスト: PCのIPアドレス
   - ポート: `8765`
   - トークン: サーバーに表示されたもの
3. 「ローカルネットワーク上のデバイスの検索」の確認が出たら、許可する（許可しないとつながらない）

ホストとポートはアプリに、トークンは iPhone のキーチェーンに保存されるので、次からは「接続」を押すだけです。

## 使い方

画面の右上のボタンで、メニューを開きます。

### 表示

- 右下の「ウィンドウ」のボタン（半開きのときは、下の画面の上の帯のボタン）か、メニューの「ウィンドウを選択」で、ウィンドウ1つだけを映す。一覧は、今映しているものが先頭で、文字で探せる。上のボタンで、小さい絵（プレビュー）の並びと、文字だけの一覧を切り替えられる。絵が取れないウィンドウ（最小化しているものなど）は、場所の色とアプリの頭文字で見分ける。「メイン画面を表示」で元に戻る
  - 「この画面に大きさを合わせる」をオンにすると、ウィンドウの大きさを、iPhoneの画面と同じ縦横比に変える。文字は、PCで見るのとほぼ同じ大きさになる。iPhoneを回したり、Duoを閉じたり開いたりしたときも、合わせ直す
  - 選んだウィンドウは前に出る。ffmpeg 8.1 以降なら、ウィンドウだけを撮るので、他のウィンドウが上に重なっても映らない。それより前の ffmpeg では、画面を切り抜くので、上に重なったものも映る（サーバーの起動のときに、どちらで撮るかを表示する。`winget upgrade Gyan.FFmpeg` で新しくできる）
  - ウィンドウを動かすと、表示もついていく。閉じると画面全体に戻る
- メニューの「モニターを選択」で、PCのモニターを1つ選んで映す。主モニター、ほかのモニター、仮想ディスプレイが一覧に出る。選ぶと、そのモニター全体を映す。つなぎ直したときは、見ていたモニターに戻る。「メイン画面を表示」で、主モニターに戻る
- Duo の角が丸く、映像の角が削れるときは、メニューの「設定」の「画面の端の余白」（なし、小、中、大）で、映像を内側に寄せられる。ウィンドウや仮想画面の大きさは、余白を除いた範囲に合わせる
- ピンチで映像を拡大・縮小する（iPhoneの中だけで、PCには送らない）。拡大中は、2本指で動かすと映像が動く。元の大きさまで縮めると、拡大が解ける

### 仮想画面（iPhone専用の作業用の画面）

PCに、仮想ディスプレイ（ソフトで作る、つながっていないモニター）のドライバーを入れると使えます。入れ方は、[docs/virtual-display.md](docs/virtual-display.md) にあります。

- メニューの「仮想画面を表示」で、仮想ディスプレイ全体を映す。PCの本物のモニターは、そのまま見えて、使い続けられる（ただし、マウスとキーボードは、PCの前の人とiPhoneで、取り合いになる。1人で、交互に使う前提）
- 仮想画面の解像度は、iPhoneの画面の縦横比に近いものにする（高さは 1080 で、幅だけを合わせる）。iPhoneを回したり、Duoを開閉したりしたときも、合わせ直す
- 本物のモニターにあるウィンドウは、「ウィンドウを選択」で、仮想画面に移せる。仮想画面を映しているときは、選んだウィンドウが、仮想画面に移る
- 「仮想画面に移して映す」をオンにすると、選んだウィンドウを仮想画面に移して、そのウィンドウだけを映す。他のウィンドウが重なっても映らない
- 移したウィンドウは、「移動したウィンドウを元に戻す」か、切断で、元の場所に戻る
- 仮想ディスプレイは、普段は無効にしておく。サーバーが、必要なときだけ有効にして、使い終わったら（「切断」ボタン、またはサーバーを止めたとき）無効に戻す。有効にするには、サーバーを管理者として起動する（`start-admin.bat`）
- 通信が切れたときは、120秒待ってから戻す。この間につなぎ直せば、続きから使える

### 画面の触り方

メニューの「設定」で、2つの方式から選びます。

| 操作 | 直接触る（初期値） | トラックパッド |
|---|---|---|
| タップ | その場所を左クリック（続けて2回でダブルクリック） | カーソルの場所を左クリック |
| 1本指で動かす | 左ボタンを押したまま動かす | カーソルを動かす（クリックはしない） |
| 長押し | 右クリック | 長押ししてから動かすと、左ボタンを押したまま動かす |
| 2本指でタップ | 右クリック | 右クリック |
| 3本指でタップ | 中ボタンのクリック | 中ボタンのクリック |
| 2本指で動かす | スクロール（指を離したあとも少し流れる） | 同じ |
| ピンチ | 映像の拡大・縮小 | 同じ |

**3本指のスワイプ**（どちらの方式でも同じ）。指を離したときに、動きが大きい方の向きで決まります（60ポイント以上動かしたとき）。

| 向き | PCでの動き |
|---|---|
| 左・右 | アプリの切り替え（Alt+Tab） |
| 上 | タスク ビュー（Win+Tab） |
| 下 | デスクトップを表示（Win+D） |

**ショートカット**: メニューの「ショートカット」から、よく使うキーの組み合わせを送れます（アプリの切り替え、タスク ビュー、エクスプローラー、タスク マネージャー、画面の切り取り、ウィンドウを閉じる、コピー、貼り付け、元に戻す、保存など）。ロック（Win+L）は、iPhone からは解除できないため、入れていません。

トラックパッドの方式では、クリックせずにカーソルを動かせるので、マウスを乗せると出る説明やメニューも出せます。

**マウス（AssistiveTouch や、つないだマウス・トラックパッド）**

| 操作 | PCでの動き |
|---|---|
| 左ボタンのクリック、ドラッグ | 指のタップ、ドラッグと同じ（左クリック、左ボタンを押したまま動かす） |
| 右ボタンのクリック | 右クリック |
| ホイール、トラックパッドの2本指のスクロール | スクロール |
| ボタンを押さずに動かす | PCのカーソルが、その位置に動く（マウスを乗せると出る説明も出る） |

- iPhone 側のカーソルは隠す（映像の中に、PCのカーソルが映るため）
- 中ボタンのクリックは、まだ対応していない（iPhone が、中ボタンを、アプリに渡さないため）

### 文字の入力

メニューの「入力方法」で、3つの方式から選びます。

| 方式 | 内容 |
|---|---|
| タッチだけ | マウスの操作だけ |
| iPhoneのキーボード | iPhone側で変換まで済ませ、確定した文字をPCに送る |
| Bluetoothキーボード | キーをそのままPCに送る。日本語の変換はPCのIMEで行う |
| アプリのキーボード | 映像の上に、PCのキーボード（HHKB に近い並び）を重ねて出す。キーをそのままPCに送る。日本語の変換はPCのIMEで行う |

- 右下のボタンで、iPhoneのキーボードを出したり、しまったりできる。PCのIMEの状態（あ / A）も、ここに出る
- iPhoneのキーボードの上には、Ctrl、Shift、Alt、Win、Esc、Tab、矢印、Home、End、BS、Del、Enter、IMEの切り替えのキーが並ぶ
  - Ctrl、Shift、Alt は、先に押しておくと、次に打った英字・数字か、次に押したキーと一緒に押したことになる（Ctrl+C、Shift+→ など）
- アプリのキーボード
  - 右下のボタンで出したり、しまったりする。ボタンで出すのは、メニューの「入力方法」で最後に選んだキーボード（iPhoneのキーボードか、アプリのキーボード）
  - 上の帯を引くと動く。帯の右端のつまみを左右に引くと、大きさが変わる。帯の × で閉じる。キーの外は、映像に触れる
  - メニューの「設定」で、配列（US か JIS）と、濃さ（100%〜40%）を選ぶ。配列は、PCのキー配列に合わせる（キーはPCの配列で文字になるため）
  - Shift、Ctrl、Alt、Fn は、押したまま、ほかのキーを押せる。1回たたくと、次のキー1つだけに付く。2回続けてたたくと、固定になる（青くなる）。もう一度たたくと外れる
  - Win は、たたくとスタートメニューが開く。押したまま、ほかのキーを押すと、Win+E などになる
  - 配列は、HHKB に近い 5 段。US は、数字の段が Esc、バッククォート、1、2、3 … の順（左上にバッククォート）。Fn を押している間は、数字の段が F1〜F12 に、バッククォートが Delete に替わる。矢印と Home、End、PgUp、PgDn は、Fn を押して、[ ; ' / と、K , L . で出す
  - 日本語の入力は、PCのIMEで行う。右下の「あ / A」のキーを押すと、PCのIMEのオンとオフが切り替わる（PCのキー配列が、US でも JIS でも同じ。今の状態が、キーに出る）。JIS の「半/全」キーと、US の Alt+` でも切り替えられる
  - 半開きでないとき、下端に固定する形（普通の iPhone のキーボードのように、画面の下に横いっぱいで出る）にできる。右下のボタンで出したり、しまったりする。高さは画面の 45% まで
  - キーボードとトラックパッドは、それぞれ、「フロート」（映像の上で動かせる）か「下部に固定」を選べる。メニューの「設定」の「キーボードの位置」「トラックパッドの位置」で選ぶ。フロートの形の帯にある「下向きの矢印」のボタンでも、下部に固定にできる。下部のキーボードの帯の右のボタンで、フロートに戻る
  - 両方を下部に固定にすると、キーボードの下にトラックパッドが並ぶ。トラックパッドは、右下のトラックパッドのボタンで出し入れする
- Bluetoothキーボードをつなぐと、自動でBluetoothキーボードの方式になる。外すと、タッチだけに戻る
  - 日本語キーボードの「英数」「かな」キーで、PCのIMEがオフ・オンになる
  - 日本語キーボードの「半角/全角」キーは、PCの IME のオン・オフを切り替える（メニューの「設定」の「半角/全角キーで IME を切り替える」。初めはオフ。日本語キーボードの人だけ、オンにする。USキーボードでは、` キーがそのまま入る。USキーボードで IME を切り替えるには、メニューのボタンか、Alt+` を使う。オンのときも、Shift+` は、そのまま送る）
  - Macのキーボードの command キーは、PCでは Windowsキーになる。メニューの「設定」で「Command キーを Ctrl として使う」をオンにすると、Ctrl になる
  - command+Tab、command+スペース、地球儀キーなど、iPhoneが先に使う組み合わせは、PCに届かない

### 半開きで使う

- Duo を半開き（ノートPCのような形。折り目が横）にすると、折り目より上に映像、下にアプリのキーボードとトラックパッドが出る
  - 下の画面の上の帯に、キーボードとトラックパッドのボタンがある。それぞれ出したり、しまったりできる。「…」のメニューも、この帯にある（上の画面の角には出ない）
  - 下の画面に縦の余りがあるときは、ノートパソコンのように、キーボードを上に、トラックパッドを下に置く。トラックパッドは、残りの高さと横幅いっぱいまで広がる。縦が足りないときは、キーボードを左に、トラックパッドを右に置く
  - キーボードだけしまうと、トラックパッドが下の画面いっぱいに広がる
  - 帯の右の「﹀」で両方しまうと、映像が画面いっぱいに戻り、下の端に出し直すボタンが出る
  - IME の切り替え（あ / A）のボタンも帯にある
- トラックパッド
  - 1本指で動かすと、カーソルが動く。たたくと左クリック、2本指でたたくと右クリック、2本指で動かすとスクロール。右端の細い帯を、1本指で上下になぞっても、スクロールする
  - 長押し（0.35秒）してから動かすと、ドラッグ
  - キーボードの横に 140 ポイント以上の余りがないときは、キーボードを狭めて場所を作る
  - クリックの場所がある（文字は出さず、薄い線で分けてある）。押している間だけ、ボタンを押した状態になる。押したまま、パッドを別の指で動かすと、ドラッグになる。タップ（1本指で左クリック、2本指で右クリック）も、そのまま使える
    - 半開きの下の画面: パッドの左端が左クリック、右端が右クリック（両手の親指で持つ形に合わせた）
  - パッドでピンチ（2本指を広げる・狭める）をすると、メニューの「設定」の「ピンチ操作」で選んだ動きになる。「映像を拡大・縮小」（初めはこちら。iPhone の中だけで、PC には送らない）か、「PC に Ctrl+ホイールを送る」（PC のブラウザー、Word、エクスプローラーなどの表示が、拡大・縮小される）
    - 重ねて出す形: パッドの下の3割を、左半分（左クリック）と右半分（右クリック）に分ける
  - 半開きでないとき（全開や外側の画面）は、重ねて出す形で使える。右下のトラックパッドのボタン（またはメニューの「トラックパッドを出す」）で出す。アプリのキーボードと同じく、上の帯を引くと動き、帯の右端のつまみで大きさが変わり、メニューの「不透明度」で透かせる。パッドの外は、下の映像に触れる
- PCのウィンドウや仮想画面の大きさは、上の画面に合わせ直す
- メニューの「設定」の「半開き時に下の画面へキーボードを表示」で、オフにできる。初めはオン
- iOS 27.1 以降の、折り目を知らせる仕組み（UIHingeInteraction）を使う。実機ではまだ確かめていない

### 音

- メニューの「PC の音声を再生」で、オンとオフを切り替える。初期値はオフ
- **オンにすると、iPhoneで再生中の他のアプリの音（YouTube など）は止まる**。オフに戻すと、他のアプリが続きを再生できる状態に戻る
- 「他のアプリの音声と同時に再生」をオンにすると、他のアプリの音を止めずに、PCの音を重ねて鳴らす
- オフのときは、アプリは音に何も触らない
- 音は、Opus で圧縮して送る。帯域は、ステレオで約 0.1Mbps、低の画質（モノラル）で約 0.05Mbps（古いサーバーにつないだときは、圧縮しない PCM で、約 1.5Mbps）
- PCが無音のときは、何も送らない。PCで音を鳴らしたときだけ、届く
- 音は、アプリを開いている間だけ鳴る。裏に回すと、接続が切れて、音も止まる
- 映像との時間のずれを合わせる処理は、まだない。音が少し遅れて聞こえることがある

### クリップボード

- メニューの「クリップボードとファイル」の「iPhone → PC」で、iPhoneでコピーした文字を、PCのクリップボードに入れる。PCで Ctrl+V を押すと、貼り付けられる
- 「PC → iPhone」で、PCでコピーした文字を、iPhoneのクリップボードに入れる
- iPhoneのクリップボードを読むときに、iPhoneが「ペーストを許可」の確認を出すことがある。「iPhoneの設定」→「DuoRemote」→「他のAppからペースト」を「許可」にすると、出なくなる
- 「PC → iPhone」は、PCのクリップボードにある中身を受け取る。文字ならiPhoneのクリップボードに入れ、ファイルや画像なら、iPhoneの一時フォルダに受け取って、共有の画面（保存、写真に追加など）を出す。画像は、iPhoneのクリップボードにも入る。複数のファイルは、まとめて1回の共有の画面に出る
- 「写真を PC に送信」「ファイルを PC に送信」で、iPhoneの写真やファイルを、PCの「ダウンロード\DuoRemote」に保存する（複数を選べる）。「…を PC のクリップボードに入れる」は、保存に加えて、PCのクリップボードにも入れる。HEIC の写真は、JPEG にして送る。送っている間は、画面の上に進み具合が出る
- 文字は10万文字まで
- 画像とファイルも送れる（1回に200MBまで）
  - iPhone → PC: 送ったファイルは、PCの `ダウンロード\DuoRemote` フォルダに入る。同じ名前があれば、「名前 (2).拡張子」になる。「クリップボードにも入れる」を選ぶと、画像（PNG、JPEG）は画像として、それ以外はファイルとして、PCのクリップボードに入る。PCで Ctrl+V を押すと貼り付けられる
  - PC → iPhone: 「PC → iPhone」で、PCのクリップボードにファイル（エクスプローラーでコピーしたもの）があればファイルを、画像があれば画像を送る（PNG。写真のような大きな画像は、JPEG にして小さくする）。どちらもなければ、文字を送る。フォルダは送れない。ファイルは合計200MBまで
- 自動では行わない（ボタンを押したときだけ）

### 接続が切れたとき

- 自動で6回までつなぎ直す。つなぎ直したら、見ていたウィンドウの表示に戻る
- 通信が静かに途切れたとき（Wi-Fi が切れたなど）も、10秒ほどで気づいて、つなぎ直す
- アプリを裏に回すと、接続を閉じる。戻ると、つなぎ直す
- 別の端末がつながって切られたときは、つなぎ直さない
- 押したままだったマウスのボタンやキーは、サーバーが離す

### 画質と遅れ

- 画質は、接続の画面か、メニューの「設定」の「画質」で選ぶ。接続中に変えると、つなぎ直す

  | 画質 | 映像の高さ | ビットレート | フレームレート |
  |---|---|---|---|
  | 高（初期値） | 元の大きさ | 8000kbps | 60fps |
  | 中 | 1080 | 4000kbps | 60fps |
  | 低 | 720 | 1500kbps | 30fps |

- 通信量の目安（1時間あたり。付加情報を含む）

  | 画質 | 音オフ | 音オン |
  |---|---|---|
  | 高 | 約 3.7GB | 約 3.8GB |
  | 中 | 約 1.9GB | 約 2.0GB |
  | 低 | 約 0.7GB | 約 0.7GB |

  映像は、画面に動きがなくても、ほぼ同じ量が流れる。モバイル回線で使うときは、低にすると、1時間で 1GB を切る
- 映像は、PCが対応していれば H.265（HEVC）で送る（NVENC の hevc_nvenc があるとき）。通信量は同じで、H.264 より きれいに映る。メニューの「設定」の「H.265 を使う」で、H.264 にもできる。今どちらで送っているかは、メニューに出る
- 「画質を通信に合わせて自動で変える」（初めはオン）にすると、映像が追いつかない、遅れが大きい、が続いたときに、画質を1段下げる。落ち着いたら（30秒）、1段ずつ戻す。選んだ画質より上にはしない。接続中に画質を変えても、つなぎ直さない
- PCとの往復の時間（遅れ）は、画面の左上に出し続ける（メニューの「設定」の「遅延を表示」で、オフにできる）
- 通信が追いつかないときは、サーバーが古い映像を捨てて、遅れがたまらないようにする（そのとき、最大2秒ほど映像が止まる）
- 接続中は、iPhoneの画面が自動でロックされない

## サーバーの管理画面

`server` フォルダの `panel.bat` をダブルクリックすると、管理画面が開きます。初回は、`start.bat` と同じ準備をします。

- 管理画面は、PCの中だけで開くページです。ほかのPCや iPhone からは開けません
- Edge があれば、普通のウィンドウのように開きます。管理画面の「開くブラウザー」で、Chrome のタブか、いつものブラウザーに変えられます。その回だけ変えるときは `panel.bat --browser chrome` のように起動します（PCを操作する Claude に頼むときは、Claude in Chrome で触れる Chrome にします）
- 管理画面を開くと、サーバーも動き出します。黒い画面は出ません
- サーバーの起動、停止、再起動ができます
- iPhone のアプリに入れる値（ホストの候補、ポート、トークン）を表示し、コピーできます
- トークンを作り直せます。作り直したら、iPhone のアプリにも入れ直してください
- 設定（ポート、フレームレート、ビットレート、映像の高さの上限、エンコーダー、モニターの番号）を変えられます。保存したあと、再起動すると使われます
- 管理者として起動し直せます（仮想ディスプレイに必要）
- 「ログインしたときに自動で起動する」のスイッチで、ログインしたときに、管理画面とサーバーを自動で起動するようにできます（タスク スケジューラに登録します。管理者として動いていないと、登録できないことがあります）
- サーバーのログを表示できます
- 「更新」で、GitHub の main の版と比べ、新しければ「更新する」で更新できます
  - git clone で取った場合は git pull、ZIP で取った場合は ZIP を取り直して上書きします
  - `server/config.json`（トークン）、`.venv`、ログは、そのまま残ります
  - 手元でファイルを変えていると、git の方式では失敗します
  - 更新のあと、管理画面は自動で起動し直すので、新しく開いたウィンドウを使います
- ウィンドウを閉じても、管理画面とサーバーは動き続けます。もう一度 `panel.bat` を起動すると、ウィンドウが開き直します。止めるときは、管理画面の下の「管理画面を終了」を押します

## ログインしたときに自動で起動する

管理画面の「自動起動」のスイッチでも設定できます。下は、手で設定する方法です。

Windows にログインしたときに、サーバーが自動で起動するようにできます。タスク スケジューラを使います。

登録するのは `server\start.bat` です。`start-admin.bat` は登録しません（確認画面を出して管理者として起動し直すためのもので、下の設定で、`start.bat` が最初から管理者として動くため）。

1. 先に `start.bat` を一度、手で動かして、準備（Python、ffmpeg、パッケージ）を済ませておく。準備の途中で入れるかを聞かれるため、自動で起動するときは答えられない
2. スタートメニューで「タスク スケジューラ」を探して、開く
3. 右側の「操作」の「タスクの作成」を選ぶ（「基本タスクの作成」ではない）
4. 「全般」のタブで、次のようにする
   - 名前: `duo-remote` など、わかる名前を付ける
   - 「ユーザーがログオンしているときのみ実行する」を選ぶ。画面を撮るため、ログインしている人の画面の中で動く必要がある
   - 「最上位の特権で実行する」にチェックを入れる。仮想画面を使うには、管理者として動く必要がある。仮想画面を使わないなら、チェックはなくてもよい。ただし、管理者として動いているアプリは、チェックがないと操作できない
5. 「トリガー」のタブで「新規」を押し、「タスクの開始」を「ログオン時」にする。「特定のユーザー」は、自分のアカウントにする
6. 「操作」のタブで「新規」を押し、次のようにする
   - 操作: 「プログラムの開始」
   - 「プログラム/スクリプト」: `start.bat` のフルパス（例: `C:\Users\自分の名前\duo-remote\server\start.bat`）
   - 「開始オプション（オプション）」: `server` フォルダのフルパス（例: `C:\Users\自分の名前\duo-remote\server`）。引用符（"）は付けない。空のままだと、`.venv` が見つからず、起動に失敗する
7. ノートPCなら、「条件」のタブで「コンピューターを AC 電源で使用している場合のみタスクを開始する」のチェックを外す。外さないと、バッテリーで動いているときは起動しない
8. 「OK」を押す
9. 登録したタスクを右クリックして「実行する」を選び、サーバーの画面が出ることを確かめる

- 画面にトークンが表示されるので、サーバーの画面を開いたままにする。閉じるとサーバーも止まる
- 自動で起動をやめるときは、タスクを右クリックして「無効」か「削除」を選ぶ

## 外出先から使う

PCとiPhoneの両方に [Tailscale](https://tailscale.com/) を入れ、同じアカウントでログインします。アプリのホストには、PCの Tailscale のアドレス（`100.x.x.x`）を入力します。

接続の画面には、ホストの欄が2つあります。「自宅」にはPCの家の中のアドレス（`192.168.x.x`）、「外から（Tailscale）」には Tailscale のアドレスを入れます（外から使わないなら、空のままで構いません）。ポートとトークンは共通です。前回つながった方から試し、4秒つながらなければ、もう一方を試します。つながったあとに切れたときも同じで、家の Wi-Fi から外に出ると、自動で外の方につながります。今の接続先は、画面右上のメニューの上に出ます。

ルーターのポートは開けないでください。インターネットから、誰でもPCにつなごうとできるようになります。

通信は暗号化していません（`ws://`）。Tailscale を通すときは、Tailscale が暗号化するので問題ありません。家の Wi-Fi（LAN）では、トークンや入力した文字が、暗号化されずに流れます。知らない人が使う Wi-Fi（ホテル、カフェなど）では、必ず Tailscale を通してつないでください。

（外出先からの接続は、まだ試していません。）

## うまくいかないとき

| 困ったこと | 確かめること |
|---|---|
| つながらない | PCとiPhoneが同じWi-Fiにいるか（ゲスト用のWi-Fiだと、端末どうしがつながれないことがある）。PCのファイアウォールで、ポート8765が許可されているか。iPhoneの「設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」で、DuoRemote がオンか |
| ファイアウォールで許可したのに、つながらない | PCの Wi-Fi が「パブリック ネットワーク」になっていると、「プライベート ネットワーク」の許可だけでは通らない。Windowsの「設定」→「ネットワークとインターネット」→「Wi-Fi」（または「イーサネット」）→ 使っているネットワーク →「ネットワーク プロファイルの種類」を「プライベート」にする。または、ファイアウォールでパブリックも許可する |
| しばらくすると切れる | PCがスリープすると、接続が切れる。スリープしたPCを、iPhoneから起こすことはできない。Windowsの「設定」→「システム」→「電源」で、スリープするまでの時間を長くするか、「なし」にする |
| 映像と操作の位置がずれる（モニターが2枚以上） | 撮っているモニターが、主モニターと違うことがある。`start.bat --output-idx 1` のように番号を変えて起動する |
| トークンが違うと言われる | サーバーを `start.bat --show-token` で起動すると、トークンをもう一度表示する |
| 映像が出ない | サーバーの画面に出ている ffmpeg のエラーを見る。同じ内容が、`server\duo_server.log` にも残る（1MBで切り替え、3つまで） |
| 一部のウィンドウが操作できない | 管理者として動いているアプリ（タスクマネージャーなど）は、サーバーも管理者として起動しないと操作できない |
| ロック画面やUACの確認画面が操作できない | Windowsの制限で、操作できない |

## まだできないこと

- 音と映像の時間を合わせること（音が少し遅れて聞こえることがある）
- ロック画面と、UAC の確認画面の操作（Windows の決まりで、操作できない）。接続している間は、PC がスリープしたり、画面が消えてロックされたりしないようにしている。接続していないときにロックされると、iPhone からは解除できない

## サーバーのオプション

コマンドプロンプトで `start.bat --fps 30` のように付けます。

| オプション | 意味 |
|---|---|
| `--port` | ポート（初期値 8765） |
| `--fps` | フレームレート（初期値 60） |
| `--bitrate` | ビットレート（kbps、初期値 8000） |
| `--max-height` | 映像の高さの上限。0で元の大きさ。通信が細いときは 1080 や 720 にする |
| `--encoder` | `auto`（初期値）、`h264_nvenc`、`libx264`。`auto` は、グラフィックボード（NVENC）が使えればそれを使う |
| `--output-idx` | 撮るモニターの番号（初期値 0）。モニターが2枚以上で、映像と操作がずれるときに変える |
| `--window-capture` | ウィンドウを表示するとき、ウィンドウだけを撮るか。`auto`（初期値。ffmpeg に gfxcapture があれば撮る）、`on`、`off`（画面を切り抜く） |
| `--show-token` | トークンを表示する |

`--fps`、`--bitrate`、`--max-height` は、アプリで画質を選ぶと、アプリの値が使われます。

設定は `server/config.json` に保存されます。トークンが入っているので、人に見せたり、コミットしたりしないでください（`.gitignore` に入れてあります）。

管理画面に関わるサーバーのファイル（`server/duo_server/` の中）:

- `control.py`: 管理画面から使う部品（サーバーの起動や停止、設定の読み書きなど）
- `panel.py`、`panel.html`: 管理画面（`panel.py` が画面（`panel.html`）を出し、画面からの操作を受ける）
- `updater.py`: 更新（GitHub の main と比べ、更新する）

### サーバーを自分で動かす

```powershell
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m duo_server
```

ffmpeg は、NVENCを使うため、`full` 版のビルドを使います（例: `winget install Gyan.FFmpeg`）。PATHに通すか、`--ffmpeg` でパスを指定します。

### サーバーのテスト

```bash
cd server
pip install -r requirements-dev.txt
python -m pytest
```

Windows以外でも動きます。画面の取得（ddagrab）と入力（SendInput）は、Windowsでしか動かないため、テストには含まれません。GitHub Actions（`.github/workflows/server-test.yml`）で、Linux と Windows の両方で回しています。

### 版の上げ方

サーバー（`server/duo_server/__init__.py` の `__version__`）とアプリ（`ios/project.yml` の `MARKETING_VERSION`）の版は、そろえておく。上げるときは、両方を同時に変える。アプリの `CURRENT_PROJECT_VERSION` も、1つ上げる。

### iPhoneアプリのビルド

Macがないため、GitHub Actions（`.github/workflows/ios-build.yml`）でビルドします。`ios/` を変えて push するか、「Actions」の「iOS build」から実行すると動きます。

- iPhone Duo の内側画面いっぱいに表示するため、`xcode-27` のランナーで、入っている中でいちばん新しい Xcode（iOS 27.1 以降の SDK）を使う。それより前の SDK でビルドすると、内側画面では iPhone 用の枠（左右が黒）で表示される。使った SDK は、ビルドの「使ったSDKを確かめる」に出る
- できた ipa は、「Releases」の「最新のビルド」（latest）に置く（毎回上書き）。ビルドの画面の「Artifacts」にもある
