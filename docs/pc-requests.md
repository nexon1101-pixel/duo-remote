# PCを操作する Claude への依頼

この文書は、Windows PC を操作する Claude に読ませるためのものです。ユーザーは、次のように伝えるだけです。

> duo-remote のリポジトリで git pull して、docs/pc-requests.md を読んで、依頼C をやってください。

（依頼A、B、C は、それぞれ別の依頼です。名前を言われた依頼だけを、やってください。
A: 切断のあとの後片付けの確認 / B: ウィンドウと音の確認 / C: iPhone で試すあいだの、サーバーの起動と見守り / D: 日本語入力（IME）の切り替えの確認 / E: サーバーの管理画面の確認 / F: ウィンドウだけを撮ることの確認 / G: 管理画面の直したところの確認）

リポジトリは `%USERPROFILE%\duo-remote` にあります（なければ `git clone https://github.com/nexon1101-pixel/duo-remote.git`）。

## 共通の決まり

- コードは書き換えない。GitHub に push しない
- サーバーのトークンは、報告に書かない
- 管理者の確認画面（UAC）は、あなたは操作できない。出たら、ユーザーに「許可を押してください」と伝えて、待つ
- サーバーは、Ctrl+C で止める。強制的に止めない（仮想モニターが有効のまま残る）
- 途中で止まったら、先に進まず、出たメッセージをそのまま報告する

## 依頼A: 切断のあとの後片付けの確認（仮想ディスプレイ）

目的: iPhone やテストが接続を閉じたあと、仮想ディスプレイが、すぐ（数秒で）無効に戻るかを確かめる。

1. 動いているサーバーがあれば、Ctrl+C で止める
2. 最新にする

   ```bat
   cd /d "%USERPROFILE%\duo-remote"
   git pull
   ```

   （ブランチ指定が必要と出たら: `git pull origin claude/keen-wozniak-41r0ni`）
3. `server\start-admin.bat` を実行する（管理者の確認画面が出るので、ユーザーに押してもらう）。「仮想ディスプレイ: 使えます」が出ること
4. 別のコマンドプロンプトで、次を実行する

   ```bat
   cd /d "%USERPROFILE%\duo-remote\server"
   check.bat --virtual
   ```

   出力を全部控える（`[OK]`、`[NG]`、「出すまで ○秒」）
5. **サーバーは止めずに**、check が終わった時刻を覚えておき、次を順に実行する

   ```bat
   virtual.bat monitors
   ```

   - 終わってから **5秒後**、**10秒後**、**20秒後** の3回。それぞれ、`【仮想】` のモニターが、あるか、ないかを控える
   - なくなるまでに、何秒かかったか（目安でよい）を控える
6. サーバーのログを控える

   ```powershell
   Get-Content "$env:USERPROFILE\duo-remote\server\duo_server.log" -Tail 40
   ```

7. サーバーの画面で、Ctrl+C を押して止める。止めたあとも、`virtual.bat monitors` で、`【仮想】` がないことを確かめる

### 報告の形

```
## check.bat --virtual の出力
（そのまま）

## 切断のあと、仮想モニターは消えたか
- 5秒後: ある / ない
- 10秒後: ある / ない
- 20秒後: ある / ない

## duo_server.log の最後の40行
（そのまま。トークンは伏せる）

## サーバーを止めたあと
- 仮想モニター: ある / ない

## そのほか気づいたこと
```

期待する結果: 5〜10秒後には「ない」。ログに「切断しました」の行がある。

## 依頼B: ウィンドウの表示、仮想画面へのウィンドウの移動、PCの音の確認

目的: iPhone を使わずに、次の3つが、このPCで動くかを確かめる。

1. ウィンドウ1つだけを映す（今のモニターの上で）
2. ウィンドウを仮想ディスプレイに持ってきて、そこだけを映し、元に戻す
3. PCの音を取って、サーバーが送れる

### 準備

1. 動いているサーバーがあれば、Ctrl+C で止める
2. 最新にする（`cd /d "%USERPROFILE%\duo-remote"` のあと `git pull`。ブランチ指定が必要と出たら `git pull origin claude/keen-wozniak-41r0ni`）
3. `server\start.bat` を1回起動して、必要なパッケージを入れ直す（音の部品が増えている）。「起動しました」と出たら、Ctrl+C で止める。パッケージのエラーが出たら、そのまま報告して、先へ進まない
4. **メモ帳（Notepad）を開く**。何か文字を打っておき、画面のどこにあるか（左上の位置）を覚えておく
   - 画面の写真（スクリーンショット）が撮れるなら、撮っておく
   - メモ帳のタイトルに含まれる文字を、控える。日本語の Windows なら「メモ帳」、英語なら「Notepad」。以下では、これを `<タイトル>` と書く
5. `server\start-admin.bat` を実行する（管理者の確認画面が出るので、ユーザーに押してもらう）。「仮想ディスプレイ: 使えます」が出ること

### 確認 1: ウィンドウ1つだけを映す

別のコマンドプロンプトで、次を実行する。

```bat
cd /d "%USERPROFILE%\duo-remote\server"
check.bat --window --title <タイトル>
```

- `[OK] 「…メモ帳」だけの表示に切り替えられました` が出ること。出力を全部控える
- このとき、メモ帳が、前に出てくる。大きさは変わらない（iPhone の画面の大きさを送っていないため）

### 確認 2: ウィンドウを仮想ディスプレイに持ってきて、元に戻す

```bat
check.bat --bring --title <タイトル>
```

- 次の4つの `[OK]` が出るはず
  - 仮想ディスプレイに持ってこられました（main → virtual）
  - 仮想ディスプレイ上の…だけを映せました
  - 元の場所（main）に戻せました
  - 画面全体の表示に戻せました
- 出力を全部控える
- 終わったあと、**メモ帳が、最初と同じ位置・同じ大きさに戻っているか**を、見て確かめる（準備 4 で控えた位置と、比べる）。スクリーンショットが撮れるなら、撮る
- 切断のあと、数秒たってから、`virtual.bat monitors` で、`【仮想】` が消えていることも確かめる

### 確認 3: PCの音

ユーザーに、「これから約1分、PCから音が鳴ります。音量を下げてよいですか」と聞いて、返事をもらってから進める。

1. 音を鳴らす。別の PowerShell で、次を実行する（約1分、アラームの音が繰り返し鳴る）

   ```powershell
   Start-Process powershell -ArgumentList '-NoProfile','-Command','$p = New-Object Media.SoundPlayer "C:\Windows\Media\Alarm01.wav"; $p.PlayLooping(); Start-Sleep 60'
   ```

2. 音が鳴っているあいだに、次を実行する

   ```bat
   cd /d "%USERPROFILE%\duo-remote\server"
   check.bat --audio
   ```

   - `[OK] 音が届きました: ○個（約○秒ぶん）、最大の音の大きさ ○/32767` が出ること。出力を全部控える
3. `[NG]` が出たときは、次も控える

   ```bat
   .venv\Scripts\python.exe -m pyaudiowpatch
   ```

   （音の入り口の一覧が出る。スピーカーの名前と、ループバックの入り口があるかを見る）

### 後片付け

1. サーバーの画面で、Ctrl+C を押して止める
2. `virtual.bat monitors` で、`【仮想】` がないことを確かめる
3. メモ帳は、閉じてよい（保存しない）

### 報告の形

```
## 準備
- パッケージの入れ直し: 成功 / エラー（あれば、そのまま）
- メモ帳の最初の位置と大きさ:
- <タイトル>:

## 確認 1（--window）
（出力をそのまま）

## 確認 2（--bring）
（出力をそのまま）
- 終わったあと、メモ帳は、最初と同じ位置・大きさに戻っていたか:
- 数秒後、仮想モニターは消えていたか:

## 確認 3（--audio）
- 音の大きさについて、ユーザーに確かめたか:
（出力をそのまま）
- [NG] のときは、python -m pyaudiowpatch の出力:

## duo_server.log の最後の60行
（そのまま。トークンは伏せる）

## そのほか気づいたこと
```

期待する結果: すべて `[OK]`。

## 依頼C: iPhone で試すあいだの、サーバーの起動と見守り

目的: ユーザーが iPhone で試しているあいだ、サーバーを管理者で動かし続け、終わったあとの後片付けを確かめる。

### 手順

1. 動いているサーバーがあれば、Ctrl+C で止める
2. 最新にする（`cd /d "%USERPROFILE%\duo-remote"` のあと `git pull`。ブランチ指定が必要と出たら `git pull origin claude/keen-wozniak-41r0ni`）
3. `server\start-admin.bat` を実行する（管理者の確認画面が出るので、ユーザーに押してもらう）。「duo_server 0.7.0 を起動しました」と「仮想ディスプレイ: 使えます」が出ること
4. このPCの IPv4 アドレス（Wi-Fi か有線の `192.168.x.x`）を調べて、ユーザーに伝える
5. サーバーの画面は、閉じずに、そのまま動かしておく。ユーザーが「終わった」と言うまで、待つ
   - 待っているあいだ、ユーザーに頼まれたときだけ、`virtual.bat monitors` や、ログの表示（`Get-Content "$env:USERPROFILE\duo-remote\server\duo_server.log" -Tail 60`）をする

### ユーザーが「終わった」と言ったら

1. ユーザーが「切断した」と言ってから **10秒待って**、`virtual.bat monitors` を実行する。`【仮想】` が、あるか、ないかを控える
2. `duo_server.log` の最後の80行を控える（トークンは伏せる）
3. サーバーの画面で Ctrl+C を押して止める。止めたあと、もう一度 `virtual.bat monitors` を実行して、控える

### 報告の形

```
・PCの IP アドレス
・切断のあと10秒たったときの、仮想モニターの有無
・duo_server.log の最後の80行（そのまま）
・止めたあとの、仮想モニターの有無
```

## 依頼D: 日本語入力（IME）の切り替えの確認

目的: iPhone の「半角/全角」キーと、IME の切り替えボタンは、サーバーに `ime`（オン・オフ）を送る。それで、PCの IME の状態が、本当に切り替わるかを確かめる。

### 準備

1. 動いているサーバーがあれば、Ctrl+C で止める
2. 最新にする（`cd /d "%USERPROFILE%\duo-remote"` のあと `git pull`。ブランチ指定が必要と出たら `git pull origin claude/keen-wozniak-41r0ni`）
3. メモ帳（Notepad）を開く。**メモ帳に、日本語入力（Microsoft IME）が使える状態にしておく**（右下の言語表示が「あ」か「A」になっていること。「ENG」のままなら、日本語のキーボードに切り替える）。タイトルに含まれる文字を控える（日本語の Windows なら「メモ帳」）
4. `server\start-admin.bat` を実行する（管理者の確認画面が出るので、ユーザーに押してもらう）

### 確認

別のコマンドプロンプトで、次を実行する。

```bat
cd /d "%USERPROFILE%\duo-remote\server"
check.bat --ime --title メモ帳
```

- 次の2つの `[OK]` が出るはず
  - IMEをオンにできました（PCのIMEの状態が、オンになった）
  - IMEをオフにできました（PCのIMEの状態が、オフになった）
- 出力を全部控える
- 実行中、メモ帳が前に出る。そのとき、画面の右下の言語表示（「あ」と「A」）が、切り替わったかを見て、報告する（スクリーンショットが撮れるなら、撮る）

### 後片付け

サーバーの画面で Ctrl+C を押して止める。メモ帳は閉じてよい。

### 報告の形

```
## check.bat --ime の出力
（そのまま）

## 言語表示（「あ」と「A」）は、切り替わったか

## duo_server.log の最後の40行
（そのまま。トークンは伏せる）

## そのほか気づいたこと
```

期待する結果: 2つとも `[OK]`。`[NG]` のときは、メモ帳の IME が日本語入力になっているかを、先に確かめて、もう一度試す。

## 依頼E: サーバーの管理画面の確認

目的: 0.13.0 で作った管理画面（`server\panel.bat`）が、Windows で決まりどおりに動くかを確かめる。管理画面は、PCの中だけで開くページで、Edge のウィンドウとして出る。サーバーは、管理画面が子のプロセスとして動かす（黒い画面は出ない）。

この依頼では、サーバーは Ctrl+C ではなく、管理画面の「停止」か「管理画面を終了」で止める。

### 準備

1. 動いているサーバーがあれば、Ctrl+C で止める。管理画面が動いていれば、「管理画面を終了」を押す
2. 最新にする

   ```bat
   cd /d "%USERPROFILE%\duo-remote"
   git checkout main
   git pull
   ```

   `server\duo_server\__init__.py` が `__version__ = "0.13.0"` であること

### 確認 1: 開く

1. `server\panel.bat` を実行する。初回は、パッケージを入れるので、少し時間がかかる。黒い画面は、準備が終わると閉じる
2. Edge のウィンドウ（アドレスバーのないもの）で、「DuoRemote サーバー」の画面が開くこと。Edge で開かず、いつものブラウザーのタブで開いたら、そのことを控える
3. 右上が「動いています」（緑の点）になること。「つなぎ方」に、このPCの IPv4 アドレス（`192.168.x.x` など）と、ポート 8765 が出ること
4. 画面全体のスクリーンショットを撮る（トークンは伏せ字のまま。「表示」は押さない）
5. 「ログ」に「duo_server 0.13.0 を起動しました」が出ていること

### 確認 2: 管理者として起動し直す、仮想ディスプレイの片付け

1. 「Windows」の「管理者として起動し直す」を押す。管理者の確認画面（UAC）が出るので、ユーザーに許可を押してもらう
2. 新しいウィンドウが開き、「管理者」の欄が、管理者として動いている表示になること。古いウィンドウは閉じてよい
3. 別のコマンドプロンプトで、次を実行する。`[OK]` と `[NG]` を全部控える

   ```bat
   cd /d "%USERPROFILE%\duo-remote\server"
   check.bat --virtual
   ```

4. 管理画面の「停止」を押す。右上が「止まっています」になること。ログに「止める合図を受け取りました」が出ること
5. 10秒待って、`virtual.bat monitors` を実行する。`【仮想】` がないことを確かめる
6. 「起動」を押して、もう一度動かす

### 確認 3: 設定

1. 「設定」のフレームレートを 30 にして「保存」を押す。「サーバーを再起動すると使われます」と出て、「今すぐ再起動」を押せること
2. `server\config.json` を開き、`"fps": 30` になっていることを確かめる（トークンの行は、報告に書かない）
3. フレームレートに 500 を入れて「保存」を押すと、エラーの知らせが出て、保存されないこと
4. フレームレートを 60 に戻して保存する

### 確認 4: ログインしたときの自動起動

1. 「ログインしたときに自動で起動する」のスイッチをオンにする
2. コマンドプロンプトで `schtasks /Query /TN "DuoRemote サーバー" /V /FO LIST` を実行し、「実行するタスク」と「ログオン モード」と「実行レベル」（最上位）を控える
3. ユーザーに、自動起動をオンのままにするか聞く。オフにするときは、スイッチをオフにして、同じコマンドで、タスクがなくなったことを確かめる

### 確認 5: ウィンドウを閉じて、開き直す

1. 管理画面のウィンドウを閉じる
2. iPhone からつなげなくても、サーバーが動き続けていることを確かめる。`netstat -ano | findstr :8765` で LISTENING が出ること
3. もう一度 `server\panel.bat` を実行する。新しく管理画面が2つ目として動くのではなく、同じ管理画面のウィンドウが開き直すこと（「ログ」に、前の内容が残っていること）

### 確認 6: 更新（ZIP の方式）

git で取ったこのリポジトリは、今が最新なので、更新は試せない。そのため、別のフォルダに ZIP で取った写しを作り、版をわざと古くして試す。

1. 管理画面の「管理画面を終了」を押す（同じポート 8770 を使うため）
2. PowerShell で、次を実行する

   ```powershell
   $dir = "$env:TEMP\duo-update-test"
   Remove-Item -Recurse -Force $dir -ErrorAction SilentlyContinue
   New-Item -ItemType Directory $dir | Out-Null
   Invoke-WebRequest https://codeload.github.com/nexon1101-pixel/duo-remote/zip/refs/heads/main -OutFile "$dir\main.zip"
   Expand-Archive "$dir\main.zip" $dir
   $init = "$dir\duo-remote-main\server\duo_server\__init__.py"
   (Get-Content $init) -replace '__version__ = ".*"', '__version__ = "0.0.1"' | Set-Content $init
   & "$dir\duo-remote-main\server\panel.bat"
   ```

3. 写しの管理画面が開いたら、「今の版」が 0.0.1、「GitHub の版」が 0.13.0 で、新しい版がある表示と「更新する」のボタンが出ること。「更新の方式」が zip であること
4. 写しの `server\config.json` のトークンの最初の4文字を控える（報告には書かない。あとで比べるだけ）
5. 「更新する」を押す。更新のログが出て、「管理画面を起動し直しました」と出ること。新しいウィンドウが開くこと
6. 新しいウィンドウの「今の版」が 0.13.0 であること。写しの `config.json` のトークンの最初の4文字が、変わっていないこと
7. 写しの管理画面の「管理画面を終了」を押す。`Remove-Item -Recurse -Force "$env:TEMP\duo-update-test"` で写しを消す

### 確認 7: 終了

1. `server\panel.bat` で、元の管理画面を開き直す
2. 「管理画面を終了」を押す
3. `tasklist | findstr /i python` で、python.exe と pythonw.exe が残っていないこと。`virtual.bat monitors` で `【仮想】` がないこと

### 報告の形

```
## 確認 1: 開く
・Edge のウィンドウで開いたか
・右上の状態、つなぎ方に出たアドレス（192.168.x.x の形かどうかだけ。数字は書いてよい）
・スクリーンショット（あれば）

## 確認 2: 管理者、仮想ディスプレイ
・管理者として起動し直せたか
・check.bat --virtual の出力（そのまま）
・停止のあと10秒の、仮想モニターの有無

## 確認 3: 設定
・保存、範囲の外のときの知らせ、config.json の fps

## 確認 4: 自動起動
・schtasks の出力（実行するタスク、ログオン モード、実行レベル）
・最後に、オンとオフのどちらにしたか

## 確認 5: 開き直す
・閉じたあと、サーバーは動き続けたか。開き直したとき、同じ管理画面だったか

## 確認 6: 更新
・更新の前と後の版、更新のログ（そのまま）、トークンが残ったか

## 確認 7: 終了
・python が残っていないか、仮想モニターの有無

## duo_server.log の最後の60行
（そのまま。トークンは伏せる）

## そのほか気づいたこと（見た目で分かりにくいところも）
```

期待する結果: どの確認も、書いたとおりになる。ならないときは、先に進まず、画面の表示とログをそのまま報告する。

## 依頼F: ウィンドウだけを撮ることの確認

目的: 0.14.0 から、サーバーは、ウィンドウを表示するとき、画面を切り抜くのではなく、そのウィンドウだけを撮る（ffmpeg 8.1 以降にある gfxcapture。Windows Graphics Capture）。ほかのウィンドウが上に重なっても映らないこと、画面からはみ出したウィンドウも全体が映ることを確かめる。

### 準備

1. 動いているサーバーがあれば止める（管理画面なら「管理画面を終了」、黒い画面なら Ctrl+C）
2. 最新にする

   ```bat
   cd /d "%USERPROFILE%\duo-remote"
   git checkout main
   git pull
   ```

   `server\duo_server\__init__.py` が `__version__ = "0.14.0"` であること
3. ffmpeg の版と、gfxcapture があるかを調べる。出力を控える

   ```bat
   ffmpeg -version
   ffmpeg -hide_banner -filters | findstr gfxcapture
   ```
