# iPhone の確認の表（0.26.0）

上から順に試して、うまくいかなかったものだけ、「何をしたら、何が起きたか」を書き足す（docs/tasks.md の F に）。1 でつまずいたら、そこで止める。

## 準備

- [ ] PC: main を pull して、`server\panel.bat` で管理画面を開く。「つなぎ方」のアドレスとトークンを見る
- [ ] iPhone: SideStore で、Releases の「最新のビルド」（latest）から DuoRemote を入れ直す。版が 0.26.0 か

## 1. つなぐ（いちばん大事）

- [ ] 家のホストに、管理画面の「自宅の Wi-Fi・有線（おすすめ）」のアドレスを入れて、接続できる
- [ ] 映像が出る。メニューに「映像: H.265」と出る
- [ ] 左上の遅れの表示が、緑（60ms 未満）か

## 2. 触る

- [ ] タップでクリック、長押しで右クリック、2本指でスクロール
- [ ] 3本指で左右にスワイプすると Alt+Tab、上は Win+Tab、下は Win+D
- [ ] メニューの「ショートカット」から、デスクトップを表示とコピーが効く

## 3. 文字

- [ ] アプリのキーボード（浮かせる形）で英字が打てる。Ctrl+C（2本指）、Fn と矢印
- [ ] 下端に固定する形に切り替えられる（キーボードとトラックパッドの、フロートと下部固定の4通り）
- [ ] iPhone のキーボードで日本語を打てる

## 4. 音

- [ ] 「PC の音を鳴らす」で、PC の音（YouTube など）が聞こえる

## 5. ファイルと画像

- [ ] クリップボードの「写真を PC に送信」で、PC の「ダウンロード\DuoRemote」に届く
- [ ] PC で画像やファイルをコピーしてから「PC → iPhone」を押すと、共有の画面が出る

## 6. 表示

- [ ] 「ウィンドウを選択」でウィンドウだけが映る。上に別のウィンドウを重ねても映らない
- [ ] ウィンドウの一覧が、小さい絵（プレビュー）の並びで出て、上のボタンで、文字だけの一覧に切り替えられる。絵が取れないウィンドウ（最小化しているもの）は、色と頭文字の表示になる
- [ ] 「モニターを選択」で一覧が出る（モニターが1枚なら1つだけ）

## 7. Duo

- [ ] 内側画面でいっぱいに出る
- [ ] 半開きにすると、上に映像、下にキーボードとトラックパッドが出る。帯のボタンで出し入れできる

## 8. 切断とつなぎ直し

- [ ] ホーム画面に戻ってからアプリに戻ると、2秒ほどで映像が戻る
- [ ] 外のホスト（Tailscale）も入れておき、家の Wi-Fi を切ると、外の方につながる（Tailscale を入れてあれば）

## 9. 0.17 から 0.18 で足したもの

- [ ] 設定の画面（メニューの「設定」）が開き、入力、アプリ内キーボードとトラックパッド、Duo、画質と表示、音声、接続の情報に分かれている
- [ ] 設定の「キーボードの位置」「トラックパッドの位置」で、フロートと下部に固定を、別々に選べる（4通り）
- [ ] 下部に固定したキーボードの、上下に、余白がほとんどない
- [ ] 下部に固定したトラックパッドの右上のボタンで、フロートにできる。フロートのトラックパッドの帯のボタンで、下部に固定にできる
- [ ] トラックパッドの右端の細い帯を、1本指で上下になぞると、スクロールする（半開き、フロート、下部に固定のどれでも）
- [ ] 右下のウィンドウ、トラックパッド、キーボードのボタンの間があいていて、同じ高さに見える
- [ ] ウィンドウのボタンで、一覧が開く。プレビューの並びと、リスト表示を、上のボタンで切り替えられる。今映しているウィンドウが先頭で、そのあとは最近映した順
- [ ] ウィンドウのプレビューが、取れたものは絵で出て、取れないものは色と頭文字の表示になる。ブラウザなど、GPU で描くウィンドウが、黒くならないか（サーバーも 0.18.3 に更新しておく）
- [ ] ウィンドウを2つ以上映すと、ウィンドウのボタンの左に、「前のウィンドウに切り替え」のボタンが出て、押すと戻る
- [ ] 設定の「キーを色分け」と「キーを押したときに振動」が、オンとオフで変わる

## 10. ゲームモード

- [ ] メニューの「ゲームモード」と、設定の「ゲームモード」が、同じスイッチで動く
- [ ] オンにすると、上半分に映像、下半分に板が出る。右下の3つのボタンとフロートのキーボードは出ない
- [ ] 半開きにすると、折り目より上が映像、下の画面が板になる。全開に戻すと、画面の半分ずつになる
- [ ] 帯の左の3つのボタン（キーボード、トラックパッド、コントローラの順）で、板が切り替わり、アプリを開き直しても、選んだものが残っている。キーボードとトラックパッドは、両方をオンにでき、上にキーボード、下にトラックパッドが出る。コントローラは、単独だけで、押すと、キーボードとトラックパッドはオフになる。キーボードかトラックパッドを押すと、コントローラはオフになる。全部をオフにすることはできない
- [ ] キーボードが板に収まり、キーを押せる
- [ ] コントローラで、十字の上下左右と、ななめ（上と右など）が押せる。PC のゲームで、ななめに動く
- [ ] 右の4つのボタンと、Start、Select、L、R が押せる。2本以上の指で、同時に押せる
- [ ] 指を離す、指を板の外に出す、ホーム画面に戻る、キーボードやトラックパッドに切り替える、ゲームモードを終わる。どの場合も、PC のキーが押したままにならない
- [ ] 歯車で「矢印キー」と「WASD」を切り替えると、押したときに送られるキーが替わる（メモ帳などで確認する）
- [ ] 押したときに振動する。設定の「キーを押したときに振動」をオフにすると、振動しない
- [ ] ボタンが押しやすい大きさで、押している間は色が付く
- [ ] 帯のウィンドウのボタンと、「…」のメニューが使える。ウィンドウを選ぶと、映像の上半分に収まる大きさになる
- [ ] 「×」でゲームモードを終わると、元の画面に戻る

## 11. UDP（通信方式）

- [ ] PC のファイアウォールで、UDP も通してある（README の「ファイアウォール」の説明）。サーバーも 0.19.0 に更新してある
- [ ] 設定の「通信方式」を「UDP」にして、つなぎ直すと、映像が出る。設定の「接続の情報」の「通信」が「UDP」になっている
- [ ] 「自動」にして、つなぐと、UDP が通る環境では「UDP」、通らない環境では「TCP」になる
- [ ] 「TCP」に戻すと、これまでどおり動く
- [ ] UDP のとき、映像が止まったり、乱れたりしたあと、1秒ほどで戻る
- [ ] UDP のとき、音（Opus）が出る
- [ ] ゲームを動かして、TCP のときより、遅れが少ないか、見比べる

## 12. コントローラの種類（ゲームパッド）

サーバーの対応した版と、PC の ViGEmBus が要る。

- [ ] 設定の「ゲーム」と、コントローラの板の歯車に、「コントローラの種類」（キーボード入力、ゲームパッド）が出る。初めはキーボード入力で、これまでどおり動く
- [ ] ViGEmBus のある PC で、ゲームパッドにすると、板の見た目が替わる（左にスティックと十字、右に A B X Y とスティック、上の角に LB LT RB RT、真ん中の上に L3 Back Start R3）
- [ ] 板の高さが小さい Duo の下の画面でも、ボタンが重ならず、押せる
- [ ] PC の「ゲームコントローラーの設定」（joy.cpl）で、Xbox 360 のコントローラが出る。左右のスティック、十字、A B X Y、LB RB、Start、Back、L3、R3 が、その表示のとおりに動く
- [ ] LT と RT を押すと最大になり、離すと 0 に戻る
- [ ] 左スティックは、板の左半分、右スティックは、右半分の、スティックの範囲に触れて、引いた向きと量で動く。離すと 0 に戻る。上に引くと、上に動く
- [ ] 2本以上の指で、左右のスティックとボタンを同時に使える
- [ ] 指を離す、板の外に出す、ホーム画面に戻る、キーボード入力に切り替える、ほかの板に切り替える、ゲームモードを終わる。どの場合も、PC のボタンやスティックが入ったままにならない
- [ ] 押したときに振動する。設定の「キーを押したときに振動」をオフにすると、振動しない
- [ ] ViGEmBus のない PC で、ゲームパッドにすると、キーボード入力で動き、板の隅に案内が出る。通知（お知らせ）も 1 回出る
- [ ] 本物のコントローラ（Bluetooth など）をつなぐと、板の隅に「コントローラ接続中」と出て、画面のコントローラが薄くなる。ゲームパッドのときだけ、ゲームに入力が届く（つないだだけでは届かない）
- [ ] 本物のコントローラの、スティック、十字、A B X Y、LB RB、LT RT（押し込みの強さも）、メニュー（Start）、ビュー（Back）、スティックの押し込み、ホームが、PC で正しく動く
- [ ] 本物のコントローラを外す、ゲームパッドからキーボード入力に替える。どちらも、PC の入力が入ったままにならない
- [ ] 振動に対応したゲームで、本物のコントローラが振動する。止まるときは、止まる。コントローラがなければ、iPhone が軽く振動する
- [ ] つなぎ直した（再接続）あとも、ゲームパッドで動く

## 14. 拡大中の2本指（トラックパッド）

- [ ] トラックパッドのピンチで、映像を拡大する（「ピンチ操作」が「映像を拡大・縮小」のとき）
- [ ] 拡大中に、トラックパッドを、2本指で動かすと、PC がスクロールせず、映像を映す位置が動く。指の向きに、映像がついてくる
- [ ] パッドが小さくても、少し動かすだけで、映像の端まで動かせる（動きが、小さすぎないか、大きすぎないか）
- [ ] 映像を元の大きさに戻すと、2本指は、これまでどおり、PC のスクロールになる
- [ ] 拡大中も、右端の細い帯は、PC のスクロール

## 15. カーソルを中央へ

- [ ] トラックパッドを、3本指でタップすると、PC のカーソルが、映像の真ん中に動く。黄色の輪が、一瞬出る
- [ ] メニューの「カーソルを中央へ」でも、同じ
- [ ] 映像を拡大して、端のほうを映しているとき、いま見えている範囲の真ん中に、カーソルが来る
- [ ] 3本指のタップで、右クリックが、一緒に出ない（2本指のタップとの区別）
- [ ] 「タッチ操作」が「タッチ」のときも、メニューから、使える

## 16. 操作しやすさ（0.21）

- [ ] 設定の画面で、位置、不透明度、通信方式、仮想画面の大きさ、画面の余白が、横並びの切り替えになっていて、1回で選べる
- [ ] 映像を拡大すると、右下（半開きのときは、下の画面の帯）に「拡大を戻す」ボタンが出る。押すと、元の大きさに戻る。戻すと、ボタンが消える
- [ ] メニューにも「拡大を戻す」が出る（拡大中だけ）
- [ ] 仮想ディスプレイが使えるとき、メニューに「仮想画面の大きさ」が出て、選ぶと、いま映している仮想画面が、新しい大きさで撮り直される
- [ ] 仮想画面の大きさを「大」「特大」にすると、縦横比は変わらず、解像度だけが大きくなる（PC の設定ファイルを書き直してある場合）

## 17. UpSnap と手入力のタブ（0.23）

- [ ] 接続の画面の上に「UpSnap」と「手入力」のタブがある。初めは UpSnap
- [ ] 手入力のタブで、ホスト、外出先のホスト、ポート、トークンを打って「接続」を押すと、つながる。0.22 までの接続先が、そのまま入っている
- [ ] UpSnap のタブで、自宅のアドレス、外出先のアドレス（任意）、メールアドレス、パスワードを入れて「ログイン」を押すと、UpSnap の PC の一覧が出る。間違えたときは、メッセージが出る
- [ ] 一覧の点が、オン（緑）、オフ（灰色）になる。UpSnap でオン・オフが変わると、数秒で変わる
- [ ] 初めてタップした PC は、接続の設定（外出先のホスト、ポート、トークン）が開く。保存したあと、もう一度タップすると、つながる
- [ ] オンの PC をタップすると「接続」、オフの PC には「電源を入れる」が出て、押すと、PC が起動して、つながったら自動で接続する（自宅の Wi-Fi と、外出先の Tailscale の両方で）
- [ ] PC がオンでサーバーが動いているときは、緑の点で「オン」。サーバーを止める（管理画面を閉じるなど）と、数秒で、オレンジの点と「オン（サーバーにつながりません）」になる
- [ ] 起動を待っている間は「やめる」で止められる。3分たってもつながらないときは、メッセージが出る
- [ ] 自宅の Wi-Fi では自宅のアドレス、モバイル回線（Tailscale オン）では外出先のアドレスでつながり、一覧の下に「自宅のアドレス」「外出先のアドレス」と出る。場所を変えても、数秒で切り替わる
- [ ] 「ログアウト」で、ログインの画面に戻る。アプリを閉じて開き直しても、ログインしたままになっている

## 18. PC の電源（0.24）

- [ ] 接続中のメニューに「PC の電源」があり、「スリープ」「再起動」「シャットダウン」を選べる
- [ ] 選ぶと、確認が出る。シャットダウンと再起動には、「強制的に…」も出る。スリープには出ない
- [ ] 「シャットダウン」を選ぶと、数秒で PC が切れ、アプリは接続が切れた表示になる。UpSnap の「電源を入れる」で起動できる
- [ ] 「再起動」で、PC が再起動する。サーバーが自動で起動したあと、また接続できる
- [ ] 「スリープ」で、PC がスリープする。UpSnap の「電源を入れる」で戻る（BIOS とアダプターの設定が必要）
- [ ] 保存していない文書を開いたまま「シャットダウン」を選ぶと、Windows が止める（強制のときは、止めずに閉じる）
- [ ] 仮想ディスプレイを使っていたとき、電源を操作したあと（再起動後）、仮想ディスプレイが無効に戻っている

## 19. 映像を固定の上に収める（0.24.1）

- [ ] 設定の「固定した部分を避けて映像を表示」は、初めはオフ。オフのときは、これまでどおり、映像の上にキーボードが重なる
- [ ] オンにして、キーボードを下部に固定すると、映像がキーボードの上の範囲に縮み、キーボードの下に映像が出ない
- [ ] トラックパッドだけを下部に固定したときも、その上に映像が収まる
- [ ] 固定をやめる（フロートにする）と、映像が画面いっぱいに戻る
- [ ] 仮想画面やウィンドウの表示のとき、映像の縦横比が崩れず、ウィンドウが収まった範囲に合う
- [ ] ゲームモードと半開きでは、設定にかかわらず、これまでどおり
- [ ] キーボードを下部に固定しているとき、フロートのトラックパッドを動かしても、固定したキーボードの裏には入らない（固定の上の範囲までしか動かせない）
- [ ] トラックパッドを下部に固定しているとき、フロートのキーボードも、同じ
- [ ] フロートを固定の裏に近い位置に置いたまま固定すると、フロートが固定の上に収まる

## 20. 一覧から電源を操作する（0.25）

- [ ] UpSnap の一覧の PC の右端のメニュー（⋯）に「接続の設定」がある。PC がオンのときは、さらに「スリープ」「再起動」「シャットダウン」が出る。オフのときは出ない
- [ ] 「シャットダウン」を選ぶと、確認が出る。実行すると、接続せずに、数秒で PC が切れる。一覧の下に「…を シャットダウンします」と出る
- [ ] 外出先（Tailscale オン）でも、同じようにできる
- [ ] トークンが未設定の PC では、選ぶと、先に接続の設定が開く
- [ ] サーバーが止まっているとき、「…できませんでした（PC に接続できません。…）」と出る

## 21. 音量と、PC のスピーカーの消音（0.26）

- [ ] 設定の「音声」に、音量のスライダーと、「接続中、PC のスピーカーを消音」がある。接続中のメニューにも、「音量」と「PC のスピーカーを消音」がある
- [ ] 音量を変えると、iPhone で鳴る PC の音の大きさが、すぐ変わる。アプリを開き直しても、音量が残っている
- [ ] 「PC のスピーカーを消音」をオンにして接続すると、PC のスピーカーから音が出なくなり、iPhone には、これまでどおり音が届く（PC の音声を再生をオンにして確認する）
- [ ] 接続中にオン・オフを切り替えると、すぐ反映される
- [ ] 切断すると、PC のスピーカーの消音が元に戻る。もともと消音にしていたときは、そのまま
- [ ] サーバーを強制終了（タスクマネージャーなど）したあと、サーバーを起動し直すと、消音が戻る
- [ ] pycaw が入っていないとき、「PC の音を消せませんでした（…）」と出る
- [ ] 音の遅れが、前の版より小さい。UDP（設定の通信方式）にすると、さらに小さくなるか
