# iPhone の確認の表（0.19.0）

上から順に試して、うまくいかなかったものだけ、「何をしたら、何が起きたか」を書き足す（docs/tasks.md の F に）。1 でつまずいたら、そこで止める。

## 準備

- [ ] PC: main を pull して、`server\panel.bat` で管理画面を開く。「つなぎ方」のアドレスとトークンを見る
- [ ] iPhone: SideStore で、Releases の「最新のビルド」（latest）から DuoRemote を入れ直す。版が 0.19.0 か

## 1. つなぐ（いちばん大事）

- [ ] 家のホストに、管理画面の「自宅の Wi-Fi・有線（おすすめ）」のアドレスを入れて、接続できる
- [ ] 映像が出る。メニューに「映像: H.265」と出る
- [ ] 左上の遅れの表示が、緑（60ms 未満）か

## 2. 触る

- [ ] タップでクリック、長押しで右クリック、2本指でスクロール
- [ ] 3本指で左右にスワイプすると Alt+Tab、上は Win+Tab、下は Win+D
- [ ] メニューの「ショートカット」から、デスクトップを表示とコピーが効く

## 3. 文字

- [ ] アプリのキーボード（浮かせる形）で英字が打てる。Ctrl+C（2本指）、Fn と矢印
- [ ] 下端に固定する形に切り替えられる（キーボードとトラックパッドの、フロートと下部固定の4通り）
- [ ] iPhone のキーボードで日本語を打てる

## 4. 音

- [ ] 「PC の音を鳴らす」で、PC の音（YouTube など）が聞こえる

## 5. ファイルと画像

- [ ] クリップボードの「写真を PC に送信」で、PC の「ダウンロード\DuoRemote」に届く
- [ ] PC で画像やファイルをコピーしてから「PC → iPhone」を押すと、共有の画面が出る

## 6. 表示

- [ ] 「ウィンドウを選択」でウィンドウだけが映る。上に別のウィンドウを重ねても映らない
- [ ] ウィンドウの一覧が、小さい絵（プレビュー）の並びで出て、上のボタンで、文字だけの一覧に切り替えられる。絵が取れないウィンドウ（最小化しているもの）は、色と頭文字の表示になる
- [ ] 「モニターを選択」で一覧が出る（モニターが1枚なら1つだけ）

## 7. Duo

- [ ] 内側画面でいっぱいに出る
- [ ] 半開きにすると、上に映像、下にキーボードとトラックパッドが出る。帯のボタンで出し入れできる

## 8. 切断とつなぎ直し

- [ ] ホーム画面に戻ってからアプリに戻ると、2秒ほどで映像が戻る
- [ ] 外のホスト（Tailscale）も入れておき、家の Wi-Fi を切ると、外の方につながる（Tailscale を入れてあれば）

## 9. 0.17 から 0.18 で足したもの

- [ ] 設定の画面（メニューの「設定」）が開き、入力、アプリ内キーボードとトラックパッド、Duo、画質と表示、音声、接続の情報に分かれている
- [ ] 設定の「キーボードの位置」「トラックパッドの位置」で、フロートと下部に固定を、別々に選べる（4通り）
- [ ] 下部に固定したキーボードの、上下に、余白がほとんどない
- [ ] 下部に固定したトラックパッドの右上のボタンで、フロートにできる。フロートのトラックパッドの帯のボタンで、下部に固定にできる
- [ ] トラックパッドの右端の細い帯を、1本指で上下になぞると、スクロールする（半開き、フロート、下部に固定のどれでも）
- [ ] 右下のウィンドウ、トラックパッド、キーボードのボタンの間があいていて、同じ高さに見える
- [ ] ウィンドウのボタンで、一覧が開く。プレビューの並びと、リスト表示を、上のボタンで切り替えられる。今映しているウィンドウが先頭で、そのあとは最近映した順
- [ ] ウィンドウのプレビューが、取れたものは絵で出て、取れないものは色と頭文字の表示になる。ブラウザなど、GPU で描くウィンドウが、黒くならないか（サーバーも 0.18.3 に更新しておく）
- [ ] ウィンドウを2つ以上映すと、ウィンドウのボタンの左に、「前のウィンドウに切り替え」のボタンが出て、押すと戻る
- [ ] 設定の「キーを色分け」と「キーを押したときに振動」が、オンとオフで変わる

## 10. ゲームモード

- [ ] メニューの「ゲームモード」と、設定の「ゲームモード」が、同じスイッチで動く
- [ ] オンにすると、上半分に映像、下半分に板が出る。右下の3つのボタンとフロートのキーボードは出ない
- [ ] 半開きにすると、折り目より上が映像、下の画面が板になる。全開に戻すと、画面の半分ずつになる
- [ ] 帯の左の3つのボタンで、キーボード、コントローラ、トラックパッドが切り替わり、アプリを開き直しても、選んだものが残っている
- [ ] キーボードが板に収まり、キーを押せる
- [ ] コントローラで、十字の上下左右と、ななめ（上と右など）が押せる。PC のゲームで、ななめに動く
- [ ] 右の4つのボタンと、Start、Select、L、R が押せる。2本以上の指で、同時に押せる
- [ ] 指を離す、指を板の外に出す、ホーム画面に戻る、キーボードやトラックパッドに切り替える、ゲームモードを終わる。どの場合も、PC のキーが押したままにならない
- [ ] 歯車で「矢印キー」と「WASD」を切り替えると、押したときに送られるキーが替わる（メモ帳などで確認する）
- [ ] 押したときに振動する。設定の「キーを押したときに振動」をオフにすると、振動しない
- [ ] ボタンが押しやすい大きさで、押している間は色が付く
- [ ] 帯のウィンドウのボタンと、「…」のメニューが使える。ウィンドウを選ぶと、映像の上半分に収まる大きさになる
- [ ] 「×」でゲームモードを終わると、元の画面に戻る

## 11. UDP（通信方式）

- [ ] PC のファイアウォールで、UDP も通してある（README の「ファイアウォール」の説明）。サーバーも 0.19.0 に更新してある
- [ ] 設定の「通信方式」を「UDP」にして、つなぎ直すと、映像が出る。設定の「接続の情報」の「通信」が「UDP」になっている
- [ ] 「自動」にして、つなぐと、UDP が通る環境では「UDP」、通らない環境では「TCP」になる
- [ ] 「TCP」に戻すと、これまでどおり動く
- [ ] UDP のとき、映像が止まったり、乱れたりしたあと、1秒ほどで戻る
- [ ] UDP のとき、音（Opus）が出る
- [ ] ゲームを動かして、TCP のときより、遅れが少ないか、見比べる
