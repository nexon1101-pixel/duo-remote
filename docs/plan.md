# 遠隔操作アプリ 素案（2026-10-30 時点）

DuoFlick の開発の途中で話し合った内容をまとめたもの。

## 目的

iPhone Duo から、自宅の Windows PC（Windows Pro、GPU は RTX 3070 Ti）を操作する。外出先からも使う。本格的に作業できる品質にする（見るだけではなく、文字をたくさん打つ）。

参考：Sill（Mac／iPhone 向けのリモートデスクトップアプリ）
https://applech2.com/archives/20261026-sill-for-mac-and-iphone-remote-desktop.html

## 決めたこと

- 使う場面：本格的な作業。画質と遅れの少なさを優先する
- iPhone 側：アプリで作る（Safari で開くページではない）
- 置き場所：DuoFlick とは別のアプリ、別のリポジトリ。アプリ本体（Swift）と Windows 側のサーバー（Python）は1つのリポジトリにまとめ、フォルダを分ける
- 最初の範囲：画面全体の表示とタッチ操作、ウィンドウを1つ選んでそれだけを表示・操作、の両方
- 入力：
  - iPhone のキーボードは、iPhone 側で変換まで済ませ、確定した文字を PC に送る
  - Bluetooth キーボードは、すべてキー操作として PC に送る（日本語の変換は PC 側の IME）
  - 日本語キーボードの「英数」「かな」キーを、IME のオン・オフに割り当てる案。IME の状態を画面の隅に出す案もある（試作で調整）
- Windows 側：Python が使える

## 考えていること（未確定）

- 映像：Windows 側でグラフィックボードを使って動画に圧縮して送り、iPhone 側で動画として表示する。画像を1枚ずつ送る方式は、長く作業するには足りない
- ウィンドウ単位：Windows の、特定のウィンドウだけを撮る仕組みを使う。選んだウィンドウの大きさを Duo の画面の比率に合わせて変えれば、拡大や縮小なしで読める。内側画面では、左にウィンドウ、右にキーボード、という並べ方もできる
- つなぎ方：外からは Tailscale のような VPN を、Windows と Duo の両方に入れる。ポートは公開しない
- 画面の操作：タップ＝クリック、長押し＝右クリック、2本指でスクロール、ピンチで拡大。画面を直接触る方式と、トラックパッドのように動かす方式の選択は未定

## 注意すること

- Mac がない。ビルドは GitHub Actions（xcode-27 のランナー）で行い、ipa を SideStore で入れる。DuoFlick と同じやり方
- 無料の Apple ID では、同時に入れられるアプリは3つまで。SideStore 自身と DuoFlick で2つ使っているため、この遠隔操作アプリを入れるとちょうど3つになる
- VPN は同時に1つだけ。SideStore の更新に使う LocalDevVPN と、Tailscale は同時には使えない。普段の使用中は影響しないが、更新のときは切り替えが要る
- 公開リポジトリにするなら、鍵・パスワード・自宅の IP アドレスなどをコミットしない（このリポジトリは非公開）

## 次にやること

1. リポジトリを作り、フォルダの構成と、通信の取り決め（映像、タッチ、キー入力）を決める
2. 最小の試作：Windows 側で画面を撮って送り、iPhone 側で表示する（全画面）
3. タッチ操作（クリック、スクロール）を足す
4. ウィンドウを選んで表示する
5. 文字送りと Bluetooth キーボードの入力を足す
6. 外からのつなぎ（VPN）を試す
